管理连接

用连接密钥证明这是你的连接。密钥只发送给本站用于这一次操作，不会保存在浏览器里。

  • 检查状态：看看连的是哪所学校、令牌还能不能用。
  • 更换密钥：旧密钥失效，换一把新的。怀疑密钥泄露时用，之后要到 Claude 里改成新密钥。
  • 删除连接：服务器上的加密记录立刻删除，无法恢复。建议同时到 Canvas 的 Settings 里把那个令牌也删掉。
  • 想作废这个连接：这里不保存任何东西，所以没有可删的。到 Canvas 的 Account → Settings → Approved Integrations 里删掉那个令牌，连接就立刻失效。

风险提示

用之前请读完。这是熟人之间分享的小工具，不是学校或 Canvas 官方的服务。

  • 运营者技术上能看到经过的数据。你的 Canvas 内容要转交给 Claude，所以会以明文在服务器内存里经过一下。本站不保存、不记录这些内容，但运营者有能力修改服务器程序，这一点你只能选择信或不信，无法验证。
  • 中转平台和 Anthropic 也会经手明文。流量会经过 Cloudflare、Vercel 这类中转或托管平台；内容最终交给你使用的 Claude，按 Anthropic 的条款处理。
  • Canvas 令牌等于你账号的全部权限。本站只用它来读，但令牌本身没有只读一说。请给它设过期时间；任何时候在 Canvas 的 Settings 里删掉它，这里的连接就立刻作废。
  • 这不符合 Canvas 的接口政策。Canvas 官方要求第三方应用通过学校授权接入，而不是让用户手动填令牌。学校可能撤销令牌或关闭这个功能，由此产生的后果需要你自己承担。
  • 连接密钥丢了无法找回，泄露了要马上处理。拿到密钥的人可以通过本站读到你的 Canvas 内容。在“管理连接”里更换或删除即可。请立刻到 Canvas 里删掉那个令牌。
  • 未成年同学请先让家长知道。成绩和作业是你的教育记录。

本站做了什么来降低风险

  • 只读：不能提交、修改或删除 Canvas 上的任何东西。
  • 站内信、同学名单、邮箱和电话、登录记录、家长账号、个人文件一律不转发；邮箱、学号、头像等字段在返回前抹掉。
  • 不用数据库。每个连接只有一份用你的密钥加密的小记录，不保存任何 Canvas 内容。
  • 什么都不保存：没有数据库，没有文件，令牌加密后只存在于你的连接密钥里。
  • 不写访问日志和内容日志。
